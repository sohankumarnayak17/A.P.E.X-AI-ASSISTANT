# APEX - AI Voice Assistant

APEX is a personal AI voice assistant built with Python and Eel.
Control your PC with your voice — open apps, search the web, play YouTube, and more.

## Features
- 🎙️ Voice recognition & text-to-speech
- 🌐 Open websites by voice command
- 💻 Launch applications instantly
- 🎵 Play YouTube videos hands-free
- 💬 Text input fallback via chat
- 🗄️ SQLite database for app & web commands

## Tech Stack
- Python, Eel, SQLite
- SpeechRecognition, pyttsx3, pywhatkit
- HTML, CSS, JavaScript, jQuery
- SiriWave.js

## Run Locally
git clone https://github.com/sohankumarnayak17/APEX.git
